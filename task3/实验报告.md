MiniMind 模型训练过程复现实验报告

# 实验目的

本次实验围绕 MiniMind 项目展开，目标是复现其小型大语言模型的训练流程，并观察模型在不同训练阶段的损失函数变化情况。实验主要完成以下内容：

1. 基于 MiniMind 开源代码复现预训练与监督微调流程；
2. 记录并绘制训练过程中的 loss 下降曲线；
3. 使用训练得到的模型进行问答测试，并与原始模型的回答效果进行对比；
4. 在可选加分项中，使用《华中科技大学研究生手册》构造领域数据，对模型进行 LoRA 微调，并测试微调后的生成效果。

实验环境与项目结构

本实验使用的代码来自 MiniMind 开源项目，项目地址为 <https://github.com/jingyaogong/minimind>。实验目录结构如下：

```text
task3/
├── minimind-master/     # MiniMind 源代码与数据集
├── out/                 # 训练后保存的模型权重
├── loss曲线图/          # 训练 loss 曲线
└── 问答测试/            # 原模型与微调后模型的问答截图
```

其中，`out` 文件夹中保存了本次训练得到的主要权重文件：

| 权重文件 | 含义 |
| --- | --- |
| `pretrain_768.pth` | 预训练阶段得到的基础模型权重 |
| `sft_handbook_768.pth` | 监督微调后得到的模型权重 |
| `lora_handbook_768.pth` | 基于研究生手册数据训练得到的 LoRA 权重 |

本次复现采用 MiniMind 默认的 768 维模型配置，主要结构参数为 `hidden_size=768`、`num_hidden_layers=8`。训练过程沿用项目提供的 PyTorch 训练脚本，重点关注训练流程与实验结果，而不对具体代码实现作过多展开。

# 实验原理与训练流程

MiniMind 是一个面向学习和复现实验的小型大语言模型项目，整体训练流程与主流大模型类似，可以分为预训练、监督微调和领域微调三个阶段。

## 预训练

预训练阶段使用通用文本数据训练模型的基础语言建模能力。模型输入一段文本 token 序列，通过预测下一个 token 来学习语言规律、基础语义关系和常见知识表达方式。

本实验使用项目中的 `pretrain_t2t_mini.jsonl` 作为预训练数据，训练脚本为：

```bash
cd minimind-master/trainer
python train_pretrain.py
```

训练完成后得到基础权重 `pretrain_768.pth`。该阶段的作用是让模型具备基本的文本续写和语言理解能力，但还不能很好地按照用户指令进行问答。

## 监督微调

监督微调阶段使用指令问答数据进一步训练模型，使模型学习“用户提问-助手回答”的对话格式，并提升指令跟随能力。本实验基于预训练权重继续训练，使用 MiniMind 项目提供的 SFT 数据。

对应训练脚本为：

```bash
cd minimind-master/trainer
python train_full_sft.py
```

相比预训练阶段，SFT 更关注回答格式、问题理解和对话能力。训练完成后，模型能够根据用户输入生成结构化、较连贯的回答。

##  研究生手册 LoRA 微调

为了完成可选加分项，本实验进一步使用《华中科技大学研究生手册》构造领域数据，并对模型进行 LoRA 微调。LoRA 属于参数高效微调方法，它冻结原模型的大部分参数，只训练少量低秩适配参数，因此训练成本较低，也适合将模型适配到特定领域。

本实验中的领域数据包括：

| 文件 | 作用 |
| --- | --- |
| `handbook.txt` | 从研究生手册整理得到的文本内容 |
| `handbook.jsonl` | 转换后的训练样本，用于 LoRA 微调 |

LoRA 微调以 SFT 后的模型为基础，使模型学习研究生手册中的培养、转专业、学籍、奖助等规则性知识。训练完成后保存 LoRA 权重 `lora_handbook_768.pth`。

# 训练结果与 Loss 曲线分析

## 预训练 Loss

![预训练 Loss 曲线](<loss曲线图/Pretraining_Loss_Curve.png>)

从预训练 loss 曲线可以看出，训练初期 loss 约为 7.5，随后快速下降，在前几千步内下降最明显。随着训练继续进行，loss 下降速度逐渐放缓，后期稳定在 1.8 左右。该曲线符合语言模型训练的一般规律：模型在初期快速学习高频语言模式，后期进入缓慢收敛阶段。

## SFT 微调 Loss

![SFT 微调 Loss 曲线](<loss曲线图/SFT Fine-tuning Loss Curve.png>)

SFT 阶段的 loss 初始约为 5.1，随后快速下降，并在后期稳定在 1.7 到 1.9 附近。与预训练相比，SFT 训练数据更偏向问答格式，模型主要学习如何按照指令组织回答。曲线整体下降明显，说明模型在对话格式和指令跟随方面得到了有效训练。

## 研究生手册 LoRA 微调 Loss

![研究生手册 LoRA 微调 Loss 曲线](<loss曲线图/Graduate Handbook LoRA Fine-tuning Loss Curve.png>)

LoRA 微调阶段的 loss 下降最为明显，初始约为 1.8 到 2.0，经过训练后迅速下降，并最终接近 0。由于研究生手册数据属于相对固定、领域集中的文本，模型能够较快拟合其中的规则和表达方式。该结果说明 LoRA 微调成功地将研究生手册相关知识注入到了模型适配参数中。

需要注意的是，LoRA loss 很低并不一定代表模型具备完全可靠的事实推理能力，它更多说明模型对训练语料中的领域表述拟合充分。因此在实际使用时，仍需要结合问答测试观察模型回答是否准确、是否存在遗漏或幻觉。

# 问答测试与效果对比

本实验分别对原模型和经过研究生手册 LoRA 微调后的模型进行了问答测试。测试截图保存在 `问答测试` 文件夹中。

## 原模型测试效果

原模型能够回答通用知识类问题，例如“什么是机器学习”，并且回答具有一定结构性，能给出定义、特点和应用场景。

![原模型通用问答示例](<问答测试/原模型/07948f900b0b37592cd968acb4ce3b36.png>)

但是在回答学校研究生管理规定相关问题时，原模型更倾向于给出泛化答案。例如对于“华中科技大学转专业程序需要遵循哪些规定”，原模型回答了课程设置、导师指导、专业认证等较通用的内容，但没有准确给出研究生手册中的具体办理流程和时间要求。

![原模型研究生手册问题示例](<问答测试/原模型/5fdad288b274f92a6b05632ba82970b9.png>)

这说明原模型虽然具备一定通用语言能力，但缺少对华中科技大学研究生手册具体条款的掌握。

## 微调后模型测试效果

经过研究生手册 LoRA 微调后，模型在学校规章类问题上的回答明显更贴近手册内容。例如在回答转专业程序时，模型能够给出“学生提交申请、导师同意、院系审核、学校审批”等流程，并提到申请时间、转入培养计划、课程认定、学籍异动等更具体的规定。

![微调后模型研究生手册问答示例](<问答测试/微调后/4db1582a5120151f35ba53741ef2cb8b.png>)

对于通用问题，微调后模型仍能正常回答，例如关于机器学习的定义、流程和任务类型的回答仍然较完整。

![微调后模型通用问答示例](<问答测试/微调后/17bb43cc2536a109e0b942d1d835860b.png>)

整体来看，微调后模型在研究生手册相关问题上表现更好，能够输出更具体、更符合学校管理文件风格的内容。这说明 LoRA 微调有效增强了模型的领域知识表达能力。

## 对比分析

| 对比项 | 原模型 | 研究生手册 LoRA 微调后模型 |
| --- | --- | --- |
| 通用问题回答 | 能够正常回答，结构较清晰 | 基本保持原有通用问答能力 |
| 学校规定类问题 | 回答偏泛化，缺少具体规定 | 能结合研究生手册给出更具体流程 |
| 领域术语与表达 | 较少出现学校管理文件中的专门表述 | 能提到院系审核、导师同意、培养计划、学籍异动等内容 |
| 回答可靠性 | 对特定学校制度掌握不足 | 领域相关性明显提升，但仍需人工核验 |

从测试结果可以看出，原模型更适合一般性问答，而经过研究生手册 LoRA 微调后的模型更适合回答校内研究生管理制度相关问题。微调没有改变模型主体结构，只通过少量 LoRA 参数完成领域适配，说明参数高效微调在小模型复现实验中具有较好的实用价值。

# 实验总结

本次实验完成了 MiniMind 模型训练过程的复现，依次进行了预训练、监督微调和研究生手册 LoRA 微调，并保存了对应模型权重。通过 loss 曲线可以观察到三个阶段均出现明显下降趋势，说明训练过程有效收敛。

预训练阶段使模型获得基础语言建模能力；SFT 阶段提升了模型的问答和指令跟随能力；研究生手册 LoRA 微调则进一步增强了模型在华中科技大学研究生管理制度相关问题上的回答效果。问答测试表明，原模型在通用问题上表现尚可，但对具体学校制度问题回答较泛化；微调后模型能够输出更贴近手册内容的流程和规定，领域适配效果明显。

本实验也说明，小型语言模型虽然参数规模有限，但通过合理的阶段式训练和领域微调，仍然可以在特定任务场景中取得较好的效果。后续如果继续改进，可以增加更高质量的问答样本、构造更多覆盖研究生手册条款的测试集，并对回答准确率进行更系统的定量评估。
